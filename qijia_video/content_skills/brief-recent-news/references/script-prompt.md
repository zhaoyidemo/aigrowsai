请把来源卡和联网研究中已核验的最新动态，写成一版面向普通关注者的中文短视频口播脚本，目标时长约 45-60 秒。

【新闻价值】
一条视频只讲清一个核心变化：发生了什么、为什么是现在、它对受众意味着什么，以及接下来最值得观察的一个信号。开场前两秒直接给出最重要的变化或反差，前五秒补足主体和影响；不开场寒暄，不用“重磅”“炸裂”“彻底改变”等没有证据的夸张判断，也不使用“看到最后”等留人话术。

【成稿与拆段顺序】
正式输出 beats 前，先在内部明确三个不额外输出的写作锚点：本片唯一要解释的核心变化、观众听完应理解的一句话、事实截止时间内能够成立的完整主张链。先写成一版从变化发生、原因或机制、现实影响推进到待观察信号的连续口播，检查结论强度与证据是否匹配；全文成立后，再按语义和听感拆成 5-8 个叙事段。不要逐段独立创作后拼接，也不要把写作锚点添加为约定之外的 JSON 字段。

【时间与来源】
严格以来源卡中的 research_fact 和对应来源为事实边界。明确区分事件发生时间、页面发布时间和本次检索截止时间；如果只知道日期，不得补造具体时刻。旧信息只能作为背景，不得包装成最新事件。官方公告可以证明官方说了什么，但不能单独证明市场效果、用户反应或未来结果；第三方判断、预测、计划和传闻必须使用准确限定语。不同来源冲突时说明不确定性，不替任何一方补全结论。

【叙事与画面语义】
按自然逻辑组织为 5-8 个叙事段：核心变化、必要背景、关键细节、现实影响、待观察信号。旁白负责事实和解释；visual_direction 只写观众必须看懂的可见主体、关系、变化或结果，不规定画风、色彩、材质、构图、景别、运镜或跨镜头连续性，这些由统一视觉编排层完成。不要要求画面模型生成新闻截图、可读文档、数据、Logo 或界面。可以出现来源卡中明确列出的真实实体名称，但不得伪造人物发言、产品画面或品牌资产。

每个叙事段只承担一个主要主张或信息任务，相邻段必须推进新事实、机制、影响、限制或观察信号，不重复同一结论。背景只保留会改变观众对当前变化理解的部分；新术语第一次出现时立即解释。写作时在内部区分事实、分析、预测和价值判断：事实直接绑定证据，分析说明推理依据，预测写明条件，价值判断不得伪装成客观结论。拆段后连续通读全部 narration；如果段落互换顺序仍然成立、删除某段不影响理解，或连接处像独立摘要的拼接，就重新组织。

完成全文后单独复核第一句和最后一段：第一句即使被单独听到，也应让观众知道谁发生了什么重要变化、为什么与自己有关；最后一段必须回答开头提出的变化意味着什么，并给出一个有证据依据的后续观察信号，不能突然升华或重复标题。

【互动与听感】
给受众一个可复用的判断框架或后续观察点，而不是机械索取点赞评论。caption 简洁补充检索截止时间和关键边界；讨论问题应具体、低压力，并允许不同判断。口播使用自然短句，关键时间点和限定语必须清楚，不输出舞台提示或会被 TTS 误读的符号。

各段信息密度尽量均衡，但不追求机械等字数。日期、金额、比例、英文缩写、产品名或多个主体会显著增加听辨负担，所在段落应主动减少其他信息，并用自然标点安排停连。按系统追加的真实配音语速目标复核全文，不通过加速朗读或省略必要限定语压缩时长。
