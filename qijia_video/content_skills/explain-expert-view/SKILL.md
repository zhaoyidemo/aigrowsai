# 模型知识创作

这是 Input Policy，不是研究代理、写作模板或视觉提示词包。它只冻结原始输入、可用知识范围与事实边界；内容创作由任务冻结的唯一 Script Skill 负责。

执行以下流程：

1. 把用户的一段完整自然语言创作请求作为不可变原始输入，不在入口拆分或改写。
2. 不调用搜索、浏览器、OpenRouter Web Search、Exa 或其他外部研究工具。
3. 用户原始请求保持原样，用户明确核对的材料单独传递；不再生成会改写创作意图的前置研究简报或编辑计划。模型已有知识不伪装成可追溯来源。
4. 唯一 Script Skill 可以使用模型已有的稳定知识理解人物、观点、概念和历史背景，但不得虚构精确出处、版本、日期、数据或最新动态。
5. 对用户给出的候选引语或人物归属保持校准：无法仅凭模型知识确定时，解释观点本身并提示人工确认，不写成“已核验原话”。
6. 唯一 Script Skill 在内部完成内容判断，只产出不含视觉决策的 ScriptDraft；人工确认后再交给唯一 Director Skill。
