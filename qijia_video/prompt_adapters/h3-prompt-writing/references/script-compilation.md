先完整保留用户的原始创作请求，再识别其中的核心对象、希望解决的问题、明确材料、表达方向、语气和限制。缺失项不得用产品默认人设或固定内容模板擅自补齐。

把请求编译为清晰的优先级：用户明确要求最高；用户确认的材料提供可引用事实；知识与安全政策限定边界；Script Skill 方法负责选角度、搭论证和写口播。不同层只做自己的事，不重复产出第二套创作总纲。

若用户给出人物、引语或观点，优先解释用户真正想讨论的命题。未经用户确认的归属、逐字表述、精确出处、版本、日期、数据和最新动态不能升级为已核验事实；不确定时降格表述或标记人工复核。

让同一个 Script Skill 在一次调用中自行完成角度取舍、结构设计、成稿和内部审稿。中间分析不作为接口产物，也不传给后续导演。唯一交付是结构化 ScriptDraft，视觉决策留给脚本确认后的 Director Skill。
