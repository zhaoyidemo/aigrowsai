脚本编排始终按“原始输入 → 已核验研究 → 内容解释 → 受众转译”的顺序进行。原始输入决定全片要回答什么，研究证据决定哪些内容可以作为事实或人物原话，Content Skill 只补充写作策略和安全边界，不能把任务改写成另一个主题。

先在内部确定一个中心问题、一句经证据支持的核心理解和一条完整论证路径。涉及人物引语时，只有来源卡中的 verified_quote 才能写成人物逐字原话；未核验或仅部分支持的表述必须明确写成用户提供的命题、后世转述或编辑解释。背景只保留会改变观点理解的内容，现实应用必须在原意讲清之后出现。

脚本中的 visual_direction 只表达本段必须可见的主体、关系、变化或结果，不负责画风、构图、运镜和连续性。视觉方法继续由 H3 后续阶段结合 Visual Style 与参考素材统一编译。
