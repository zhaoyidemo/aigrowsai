先判断输入模式，再写提示词。本工作台的首帧在没有参考图时按文本生成图像处理，有全局参考图时按参考素材约束的图像生成处理；所有视频都由已选首帧继续生成，按 I2V 处理。

直接读取冻结的 CreativeBrief 和完整旁白，不读取脚本阶段遗留的逐段画面指令。先建立全片连续性账本：核心主体、身份特征、空间、关键物件、时间光线和状态变化。

镜头边界由语义变化决定：论证目标、主体关系、时间空间或可见状态发生改变时才切镜；不为凑数量复制旁白或重复构图。通常一段自然叙事对应一个视觉章节，只有相邻段共享同一可见动作时才合并。

图片是默认媒介；只有当连续动作、状态转变或镜头运动对理解不可替代时才使用视频。全片最多安排三段 AI 视频，但不要求凑满。随后按“构图与景别 → 主体及空间关系 → 环境 → 初始动作状态 → 光色材质 → 连续性锚点”写首帧；视频再按“首帧锚定 → 动作开始 → 连续发展 → 结果或反应”写动作路径。最终提示词只保留媒体模型能够执行和观察的具体描述。
