先判断输入模式，再写提示词。本工作台的首帧在没有参考图时按文本生成图像处理，有全局参考图时按参考素材约束的图像生成处理；所有视频都由已选首帧继续生成，按 I2V 处理。

先建立全片连续性账本：核心主体、身份特征、空间、关键物件、时间光线和状态变化。随后逐章提炼唯一的可见语义目标，按“构图与景别 → 主体及空间关系 → 环境 → 初始动作状态 → 光色材质 → 连续性锚点”写首帧；视频再按“首帧锚定 → 动作开始 → 连续发展 → 结果或反应”写动作路径。只有在有助于叙事时才加入运镜，并明确运镜类型、幅度和速度。最终提示词只保留媒体模型能够执行和观察的具体描述，不包含方法说明、字段标签、推理过程或重复限制。
